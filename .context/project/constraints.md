# Ограничения

- Исходный APK нельзя изменять.
- Репозиторий публичный; никакие личные сведения, токены и переписки не публиковать.
- Нельзя выдавать статические признаки за подтверждённые сетевые обращения.
- Не подключать без необходимости официальную или стороннюю документацию в качестве доказательства фактического поведения приложения.
- Приоритет у проверки фактическими журналами и воспроизводимыми программами.
- Политика repo-factory сохраняется для истории Git. 15.10.2026 владелец разрешил одно исключение для исследуемого бинарного файла: исходный `base.apk` MAX 26.35.1 (SHA-256 `e809176d6bf6ff69247274433ec170a5db8a5687a02a04299a78a2ae978119fc`) хранить как вложение текущего выпуска GitHub Release, без добавления в историю Git. Остальные сборочные артефакты и старые выпуски очищаются по прежней политике.
- По рабочим правилам владельца: консервативная оценка, русские пояснения, задержка между внешними обращениями не менее 5 секунд.
