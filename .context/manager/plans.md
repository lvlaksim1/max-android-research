# План менеджера MAX Android Research

1. Восстановить контекст из ветки `main`, сверить проектные цели, ограничения, реальные исходные файлы и последнюю историю коммитов.
2. Проверить эталонный APK по SHA-256 и создать воспроизводимый список элементов архива при наличии доступного образца; без образца указать отсутствие подтверждения.
3. Провести глубокий статический анализ кода и библиотек, записывая отдельно доказанные признаки и гипотезы.
4. Реальный сетевой обмен и авторизацию проверять только по разрешённым журналам работающего приложения; без таких журналов оставлять статус `не доказано`.
5. Фиксировать результаты, действующие обязательства и критерии проверки в постоянном контексте; хранить крупный бинарный образец вне истории Git согласно проектной политике.

Источник: `.context/current/next.md`, `.context/project/goals.md`, `.context/project/constraints.md`. Этот план не означает, что перечисленные действия уже завершены.
