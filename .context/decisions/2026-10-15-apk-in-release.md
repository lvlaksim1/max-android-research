# Решение: публичный эталонный APK в выпуске GitHub

Дата: 15.10.2026. Источник: прямое указание владельца в чате и подтверждённый журнал публикации GitHub Actions.

Владелец потребовал хранить полный исходный APK внутри публичного исследовательского репозитория и разрешил исключение из правил хранения тяжёлых файлов. Техническое решение: хранить байт-в-байт идентичный `base.apk` как вложение GitHub Release, потому что жёсткий лимит GitHub запрещает Git-объект размером 133 730 048 байт. Глобальная политика `repo-factory` не менялась.

- Репозиторий: `lvlaksim1/max-android-research`.
- Выпуск: `apk-26.35.1-6867`.
- Файл: `base.apk`.
- Размер: 133 730 048 байт.
- SHA-256: `e809176d6bf6ff69247274433ec170a5db8a5687a02a04299a78a2ae978119fc`.
- Прямая загрузка: https://github.com/lvlaksim1/max-android-research/releases/download/apk-26.35.1-6867/base.apk
- Контроль: проверка SHA-256 исходного образца при исследовании, повторная проверка в GitHub Actions при загрузке с RuStore, SHA-256 digest самого вложения GitHub.
- Опубликованный результат: `https://github.com/lvlaksim1/max-android-research/releases/tag/apk-26.35.1-6867`.

История Git хранит исходные сведения, программы и результаты анализа. Для воспроизводимости исследователь скачивает `base.apk` из выпуска, проверяет SHA-256 и распаковывает локально. До замены эталона соблюдать привязку к указанному SHA. Не публиковать личные данные, токены авторизации и записи переписок.
